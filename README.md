# Garden

**Knowledge → Solutions**

Garden — система непрерывного формирования и развития инженерного знания, из которого рождаются решения.

В основе Garden лежит идея, что **главным активом инженерной организации является накопленное знание**. Документы, требования, решения и другие артефакты — лишь различные представления этого знания.

Garden рассматривает инженерную работу как непрерывный цикл:

**Intent → Knowledge → Development → Selection → Solution → Knowledge**

Знание развивается через работу над решениями: новые варианты формируются, проверяются по заданным критериям, лучшие сохраняются, а полученный опыт становится частью следующего цикла.

### Основные принципы

* **Continuity** — развитие не заканчивается созданием решения.
* **Knowledge First** — накопленное знание является основным инженерным активом.
* **Determinism** — развитие происходит в заданной структуре, с чёткими границами и критериями.
* **Selection** — варианты решений проходят проверку и отбор.
* **Evolution** — система может изменять и оптимизировать существующие состояния.
* **History & Rollback** — предыдущие состояния и опыт сохраняются и могут использоваться для дальнейшего развития.

### Метафора

Garden — это ухоженный сад.

**Намерение — семя.
Знание — почва.
Процесс — выращивание.
Критерии — селекция.
Решение — плод.
Опыт — то, что остаётся в саду и влияет на его дальнейшее развитие.**

Garden не стремится просто производить больше документов или требований. Его задача — **создавать среду, в которой инженерное знание непрерывно развивается и превращается в качественные решения**.
