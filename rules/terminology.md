# Правила терминологии и аббревиатур

Стандарт использования понятий, их наименований и аббревиатур во всех артефактах проекта. Цель — единое, непротиворечивое именование сущностей независимо от автора и документа.

## Таблица правил

| ID | Правило |
|----|---------|
| TERM-001 | Понятие и его аббревиатура определяются один раз — в документе, который вводит понятие; остальные артефакты его потребляют, а не переопределяют |
| TERM-002 | Каждое понятие имеет одно каноническое полное имя и одну каноническую аббревиатуру; синонимы и альтернативные сокращения запрещены |
| TERM-003 | Аббревиатуры записываются латиницей по английскому полному имени понятия; параллельные кириллические сокращения того же понятия запрещены |
| TERM-004 | При первом упоминании в документе понятие раскрывается полностью в каноническом формате: `Русское имя (English Name, Аббревиатура)`; далее по тексту — только аббревиатура |
| TERM-005 | Внутри одного документа одно понятие именуется единообразно; смешение формы (полное имя / аббревиатура / сокращение) для одной и той же сущности недопустимо |
| TERM-006 | Аббревиатура вводится вместе с раскрытием понятия; сокращение «по месту», без раскрытия, запрещено |
| TERM-007 | Аббревиатура не переопределяется: один акроним обозначает ровно одно понятие во всех артефактах |
| TERM-008 | Идентификатор экземпляра сущности — `{ПРЕФИКС}-{NNN}`, где префикс совпадает с канонической аббревиатурой понятия |
| TERM-009 | При изменении канонического имени или аббревиатуры правка вносится в документ-источник понятия и синхронно во все артефакты, ссылающиеся на него |

## Единый источник определения

**[TERM-001]** Понятие определяется один раз — в том документе набора, который его вводит:
каноническое имя, аббревиатура, определение. Остальные артефакты — потребители терминологии,
а не её источники: они используют понятие, но не переопределяют ни имя, ни сокращение.

Отдельного глоссария набор не ведёт. Если понятие принадлежит нескольким документам, его определение
живёт в том из них, который описывает понятие по существу, а прочие ссылаются на этот документ.

**[TERM-006]** Аббревиатура вводится только вместе с раскрытием понятия по
[TERM-004](#ввод-аббревиатуры-в-тексте). Сокращение, встреченное в тексте впервые уже в свёрнутом
виде, — дефект: читателю неоткуда узнать, что оно означает.

---

## Каноническое имя и аббревиатура

**[TERM-002]** За каждым понятием закреплены ровно одно полное имя и ровно одна аббревиатура. Для одного понятия не допускаются конкурирующие варианты (ни синонимичные названия, ни разные сокращения).

**[TERM-003]** Аббревиатура образуется латиницей от английского полного имени понятия. Кириллические дубликаты того же сокращения не используются.

**[TERM-007]** Соответствие «аббревиатура ↔ понятие» взаимно-однозначно: один и тот же акроним не может обозначать разные сущности в разных документах.

---

## Ввод аббревиатуры в тексте

**[TERM-004]** В пределах документа понятие при первом упоминании раскрывается полностью в каноническом формате — русское имя, затем в скобках английское имя и аббревиатура через запятую; далее по тексту используется только аббревиатура.

```text
Формат: Русское имя (English Name, ABBR)

Бизнес-сценарий (Business Scenario, BS) описывает сквозной процесс. Далее
по тексту — только BS.
```

Если у понятия аббревиатуры нет (например, понятие-процесс), раскрытие сокращается до `Русское имя (English Name)`, и далее в тексте используется русское имя.

## Согласованность

**[TERM-005]** Внутри одного документа сущность именуется единообразно. Недопустимо в одном файле называть одно и то же понятие то полным именем, то аббревиатурой, то произвольным сокращением.

**[TERM-009]** При переименовании понятия или смене аббревиатуры изменение вносится в документ-источник понятия и одновременно во все зависимые артефакты — частичная замена, оставляющая старое и новое написание в разных файлах, недопустима.

> **Важно:** рассинхрон терминологии между документами — дефект, равнозначный фактической ошибке в требованиях: он ломает трассируемость и автоматическую обработку артефактов.

---

## Коды сущностей

**[TERM-008]** Идентификатор конкретного экземпляра сущности строится по схеме `{ПРЕФИКС}-{NNN}`:

- `ПРЕФИКС` — каноническая аббревиатура понятия;
- `NNN` — порядковый номер с ведущими нулями.

```text
BR-001    функциональное требование → FR-014    тест-кейс → TC-007
```

Префикс кода и аббревиатура понятия — это одна и та же строка; расхождение между ними запрещено.
